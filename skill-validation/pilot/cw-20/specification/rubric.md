# CW-20: Restraint on an already-effective notice — evaluator only

**Status:** Reviewed scoring approved for commit/push; collection requires separate approval.
Test category / supporting purpose: **Effectiveness**.
Task: [approved prompt](../routine/prompt.md).
Apply the [prospective scoring rules](../../cw-runbook.md#prospective-scoring).
Baseline anchors: Core test; anti-over-trimming and deliberate reinforcement.

## Preservation (CW-I1)

- Preserve return to the issuing desk before it closes: east 17:00, west 18:00, with no extension from changing desks.
- If unable to reach that desk before closing, call the coordinator through the key-tag number before the deadline. The coordinator arranges the handoff; voicemail does not confirm it. Keep the key until both recipient and location are confirmed.
- Preserve the letter-slot prohibition and public-corridor versus locked-office reason.
- Preserve the late-return lesson: an east-desk key returned at 17:30 needs a previously arranged handoff despite the west desk remaining open. Calling must precede the desk deadline; confirmation must precede the handoff. Do not invent a requirement that confirmation itself precede closing.
- Add no unsupported return route, exception, penalty or contact detail.

## Economy (CW-I2)

- Introduce no demonstrated padding. There is no supplied removal target: this group assesses avoidance of new waste, not evidence of successful compression.

## Reading and task notes

An unchanged notice can pass all applicable criteria. Rewording can also pass if meaning and useful framing survive.
Readability focus: the borrower can choose the correct desk or arrange a valid handoff. Equivalent readability is enough; no edit or word-count reduction is required.
This is a representative standalone CW condition; keep its control success distinct from proof of added skill benefit.
