# Session behavior

This page explains session behavior.
It describes the behavior of a session in the sections that follow.

## While signed in

This section covers what happens while you are signed in.

### Inactivity

The following sentence describes the inactivity timeout.

#### Timeout duration

Sessions expire after 20 minutes of inactivity.

### Activity

The following sentence describes which activity resets the timer.

#### Accepted input

Mouse, keyboard, or touch input resets the inactivity timer.

## When a warning appears

This section describes the warning that appears.

### Warning timing

A warning appears two minutes before expiration.

### Continuing the session

Mouse, keyboard, or touch input clears the warning and resets the inactivity timer.

## After expiration

This section explains what to do after expiration.

### Recovery

Expired sessions require signing in again.

Work read-only within the supplied fixture.
Do not edit files, change Git state, inspect outside the fixture, use the network, or dispatch agents.
