# CW-03 routine: whole-document revision — evaluator only

Test category / supporting purpose: **Effectiveness**.
Primary purpose: remove distant duplication while preserving useful reinforcement and navigation in a complete guide.
Apply the [routine-suite assessment rules](../../cw-runbook.md#routine-suite-assessment).

| Invariant | Criterion and pass/fail boundary |
|---|---|
| CW-I2 | Remove the guide/issuing-section meta narration, the second opening definition, the definition repeated in What the recipient sees, and the redundant last administrator/expiry sentence in Troubleshooting. Equivalent padding in new words also fails. |
| CW-I1 | Preserve single use, expiry 30 minutes after issue, one recipient's report without an account, and issuance by an administrator from the report page. A shorter definition may serve the whole document. |
| CW-I1 | Preserve checking the request address, the suggested-address distinction, resolving a mismatch with the requester before issue, and direct delivery to the confirmed recipient rather than a shared mailbox. |
| CW-I1 | Preserve report ID and issue-time ticket records, no URL in the ticket, and the rationale that ticket readers could use it. |
| CW-I1 | Preserve the report-name preview, successful Open report consuming the link, a pre-open network failure leaving it unused without extending expiry, and closing a successfully opened report not restoring access. |
| CW-I1 | Keep the failed-attempt timing lesson understandable: an 11:00 issue still expires at 11:30 despite an 11:25 failed attempt. Equivalent times or integrated explanation can work if the reader can apply the unchanged expiry to a delayed first attempt. |
| CW-I1 | Preserve troubleshooting using prior successful opening and ticket issue time; used or expired links need administrator replacement, while unused and unexpired links permit retry. Equality at 30 minutes is expired. |
| CW-I1 | Staff replacing a link can find the recipient recheck, forwarded-conversation risk and new-time-not-URL recording cautions. Local instructions, a useful cross-reference or clear organization can supply this function; fail only when finding or applying the cautions becomes materially harder. |
| CW-I1 | Staff can readily check recipient confirmation, direct delivery and time-not-URL recording, and locate the retry/replacement decision. A closing recap may repeat facts, but neither its placement nor an explicit section pointer is mandatory when the complete guide supports these uses. |
| CW-I1 | Add no unsupported access behavior, policy, recovery step or promise. |

The source map deliberately distinguishes redundant definitions from reinforcement used while sending or replacing a link and the closing checklist.
An “every fact exactly once” rewrite can fail conservation even if it removes all targeted padding.
Conversely, copying the complete source preserves meaning but fails CW-I2.
Score preservation across the whole artifact; do not demand original sentence order or heading text.
