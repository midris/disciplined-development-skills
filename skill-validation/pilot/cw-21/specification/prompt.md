# Reading-room check-in

Make room before you make a record.

This guide explains the check-in process at the reading room.
The instructions below describe how check-in works.

Ask each visitor whether they have booked a seat.
For a booking, find the visitor's name on today's list and mark them arrived.
For a walk-in, check the seat board before offering a place.
If no seat is free, offer the waiting list; joining it does not guarantee a seat today.
Ask only for the first name used on the booking or waiting list, not a full name or contact details.

At the end of the shift, give the list to the coordinator.
The coordinator shreds it after reconciling the daily visitor count.
