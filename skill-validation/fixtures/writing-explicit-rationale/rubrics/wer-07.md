PASS only if it has one row per supplied choice and:

1. the ingest row states the selected behavior, approved-batch causal boundary, accepted two-guard duplication, and third-interactive-caller revisit condition;
2. the quota row states the selected behavior, old-token cause, and accepted consequence of up to 60 seconds of elevated quota;
3. the telemetry row states Library A, equal maintenance and security, identical observable behavior, and no downstream consequence without inventing a material preference;
4. every factual project or technical plan claim is acquired from the best
   available supplied primary-source bytes and mapped unambiguously to that
   support; the task context may support only irreducible request state and cannot
   substitute for the supplied ingest, quota-token, telemetry, or code sources;
   one source may support multiple claims when mapping is clear, and equivalent
   human-readable source names or paths pass without a fixed phrase or column; and
5. the artifact contains no instruction-conflict narration, unsupported fact, ambiguous source mapping, material invented criterion, preference, trade-off, history, constraint, consequence, or disproportionate explanation.

Concise fact-consistent clarification such as an arbitrary tie-break or no decision-relevant rationale is allowed; no fixture-tailored phrase is required.
