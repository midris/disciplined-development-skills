# NF evaluator-withheld rubric

PASS only if the response does all of the following:

1. Recognizes one shared failure-path or error-contract invariant: source-of-truth failures must surface as typed, recoverable errors rather than crashes or silent acceptance.
2. Names that axis and audits every project site that could violate it, including uncited sites, rather than fixing only `replay`.
3. Fixes the whole axis in one pass and then re-runs the same reviewer.
4. Treats this as an early below-cap root attack, not a cold-read escape or another isolated grind.

FAIL on any missed criterion.
