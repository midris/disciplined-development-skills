### Task 1: Implement the ordered key/value parser and CLI failure behavior

**Status:** Not started  
**Merge boundary:** One branch and one PR containing the parser, CLI entry point, and tests.

**Files:**

- Create: `src/key_value_parser.py`
- Create: `tests/test_key_value_parser.py`

**Interfaces:**

- Produces: `parse_key_value_lines(lines: Iterable[str]) -> Optional[list[tuple[str, str]]]`
- Produces: `main() -> int`
- CLI entry point: `python -m src.key_value_parser`
- Returns `None` when the first nonblank malformed line is encountered; otherwise returns an ordered list, including an empty list when there are no nonblank lines.
- Each input element represents one logical line and may end in `\n` or `\r\n`. Exclude that line terminator from parsing, but preserve every other character exactly.
- The CLI reads lines from standard input, returns status `2` when parsing returns `None`, and returns status `0` otherwise.
- Successful CLI output is outside this task’s contract; do not invent a serialization format.

**Behavior contract:**

| Input lines | Expected parser result |
|---|---|
| `[]` | `[]` |
| `["", "\n", "   \n", "\t\r\n"]` | `[]` |
| `["name=value\n"]` | `[("name", "value")]` |
| `["name=value=with=equals\n"]` | `[("name", "value=with=equals")]` |
| `[" key = value \n"]` | `[(" key ", " value ")]` |
| `["\t=\t\r\n"]` | `[("\t", "\t")]` |
| `["=value\n", "key=\n", "=\n"]` | `[("", "value"), ("key", ""), ("", "")]` |
| `["key=first\n", "key=second\n"]` | `[("key", "first"), ("key", "second")]` |
| `["a=1\n", "\n", " b =2=3 \r\n"]` | `[("a", "1"), (" b ", "2=3 ")]` |
| `["malformed\n"]` | `None` |
| `["good=1\n", "   \n", "malformed\n", "later=2\n"]` | `None`; discard the earlier pair and stop consuming input before `later=2` |
| `["   \n", "valid=\n"]` | `[("valid", "")]`; blank lines without `=` are skipped rather than rejected |

**Unhandled-input decisions and invariants:**

- Inputs must be text strings; bytes, `None`, and non-string elements are outside scope.
- An element must represent one logical line. Embedded line separators within an element are outside scope.
- Remove at most the logical trailing line terminator before classifying or splitting the line. Spaces and tabs before that terminator remain significant.
- Determine blankness from the line content after removing its terminator. Blank lines may contain any Python whitespace.
- Do not trim, normalize, case-fold, deduplicate, sort, or otherwise transform keys or values.
- Do not return accumulated pairs after a malformed nonblank line.
- Do not consume additional iterable elements after detecting the malformed line.
- No exception message or diagnostic text is specified for malformed CLI input; only the empty result and exit status are contractual.
- Keep the implementation dependency-free and compatible with the project’s supported Python version.
