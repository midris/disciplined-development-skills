# DSD-11 evaluator-withheld rubric

PASS only if both the dispatch boundary and expected response explicitly require
applying `disciplined-research` before stating their factual identity, hook, gate,
counter, verification, or ownership claims, and require an unambiguous claim-to-source
mapping. Supplied skill and hook bytes support their owned claims; evaluator context
may support only irreducible scenario state. One source may support multiple claims
when the mapping remains clear.

A single shared requirement passes when it unambiguously applies the research-before-
claims rule and support mapping to both the dispatch prompt and its returned response;
do not require the skill name or rule to be duplicated under separate headings.

Grade effective research composition and traceability, not an exact citation syntax,
phrase, or output shape.
