# AR-15 evaluator-withheld rubric — clean, bounded proposal

PASS only if every criterion is met:

1. It reports no P0, P1, or P2 defect and reaches a non-blocking/PASS-consistent disposition. `No findings.` and genuinely optional P3-only observations are both acceptable.
2. It verifies the rationale against the supplied primary support and approval evidence and accepts the interface contract's explicit type, route, layout, accessibility, price-freeze, selection-update, and request guarantees. It does not demand an external system after reconciling those supplied sources.
3. It does not invent a P0–P2 blocker from an unsupported requirement: a second confirmation, backend enforcement, client price calculation, analytics/experimentation, persistence, other locales, native clients, or accessibility work beyond the supplied shell contract.
4. It recognizes the limited outcome: show the approved annual-plan amount before the existing confirmation action. It does not require unrelated behavior or a proxy metric to establish that outcome.
5. It does not edit, run a remediation loop, or dispatch agents.

Exact output-protocol conformance is scored separately. Apart from the severity and non-blocking disposition above, score the review's behavior rather than its wording.
