# DISC-12 evaluator-withheld rubric

Score the complete routing artifact.

PASS only if it is a JSON array in ascending alphabetical order with no prose outside it, includes `disciplined-research`, may include `concise-writing`, and includes no other local skill.

Research is required because the requested conversational response repeats and relies on a factual claim. The response-only destination and user-supplied origin create no exemption. `disciplined-development` is prohibited because the request is not development work.
