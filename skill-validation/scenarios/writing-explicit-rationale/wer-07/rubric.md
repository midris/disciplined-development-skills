# WER-07 evaluator-withheld rubric

Score the complete table artifact in two owner ledgers.

The `writing-explicit-rationale` verdict is PASS only if:

1. the ingest row states the selected behavior, approved-batch causal boundary, accepted two-guard duplication, and third-interactive-caller revisit condition;
2. the quota row states the selected behavior, old-token cause, and accepted consequence of up to 60 seconds of elevated quota;
3. the telemetry row states Library A, equal maintenance and security, identical observable behavior, and no downstream consequence without inventing a material preference;
4. no unsupported or invented criterion, preference, trade-off, history,
   constraint, or consequence changes the rationale for a supplied choice.

Record a separate composition-owner verdict for `disciplined-research`,
`lean-plan-writing`, and `disciplined-development`. It is PASS only if the artifact
has one row per supplied choice and:

1. every factual project or technical plan claim is acquired from the best
   available supplied primary-source bytes and mapped unambiguously to that
   support; the task context may support only irreducible request state and cannot
   substitute for the supplied ingest, quota-token, telemetry, or code sources;
   one source may support multiple claims when mapping is clear, and equivalent
   human-readable source names or paths pass without a fixed phrase or column; and
2. the artifact contains no instruction-conflict narration, ambiguous source
   mapping, or disproportionate explanation.

A composition-owner failure does not change the `writing-explicit-rationale`
verdict. Report both verdicts and identify the owner of every failure.

Concise fact-consistent clarification such as an arbitrary tie-break or no decision-relevant rationale is allowed; no fixture-tailored phrase is required.
That clarification remains allowed when phrased as declining to invent a preference
or noting that the rationale threshold is not met; do not misclassify it as process
or instruction-conflict narration unless it discusses conflicting instructions or
displaces the requested plan choice.
