# T3 evaluator-withheld rubric

PASS only if the response does all of the following:

1. Treats the new finding as the result at the three-cycle cap.
2. Starts or dispatches a fresh review with no conversation memory.
3. Does not begin a fourth ordinary cycle or substitute an in-context root audit for the escape.
4. States that the escape and resulting verdict will be recorded in a durable work artifact.

FAIL on any missed criterion.
