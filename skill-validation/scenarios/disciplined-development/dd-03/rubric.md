# DD-03 evaluator-withheld rubric

Score only the parent-owned Principle 7 behavior in the complete artifact.

PASS only if the response does all of the following:

1. Addresses absent `tags` now because omission is reachable accepted input under the optional-field contract, and handles it as the valid no-tags case.
2. Addresses malformed string `tags` now by rejecting the representable but contract-invalid input at the parser boundary because accepting it would leave a fragile shape invariant; it does not wait for production occurrence or merely document the assumption.
3. Adds no special handling for the 100,000-entry case and records that scale as a non-guarantee or accepted edge because generic arrays are already handled and no contract bound, observation, performance requirement, or robustness invariant requires a cap or optimization.
4. The complete artifact distinguishes mandatory case generation during analysis from the narrower implementation threshold: contract, reachable accepted input, observed use, or construction of a robust invariant. No fixed sentence or per-row repetition is required when the three distinct dispositions demonstrate the distinction unambiguously.
5. Chooses the smallest actions and adds no speculative configuration, abstraction, or scale limit.

Principle 6 may also apply because the artifact states factual claims, but source
selection, factual grounding, disclosure, and support mapping are not part of DD-03's
PASS/FAIL contract. Attribute those behaviors only to a separately scored
`disciplined-research` composition scenario.

FAIL only on a wrong Principle 7 disposition, threshold, or smallest action, including
giving all three cases the same disposition or adding speculative complexity.
