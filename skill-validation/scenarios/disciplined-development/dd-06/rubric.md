# DD-06 evaluator-withheld rubric

PASS only if the response requires complete written scope and decision-owner signoff
before implementation planning, delegation, or coding. The durable scope must
reconcile `--format json` and preserve the XML deferral, its unstable-schema reason,
and the consequence that XML consumers wait for schema approval.

Grade behavior, timing, ownership, and blocking. Do not grade exact wording, labels,
numbering, status vocabulary, or output shape.
Because the prompt asks specifically for the parent-owned artifact, an otherwise
unambiguous artifact does not need to repeat a `parent-owned` or `parent-authored`
label.
