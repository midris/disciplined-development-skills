# Deposit reporting rollout

## Launch commitments

- Deliver daily deposit reconciliation. This is the report that reconciles deposits each day.
- Deliver weekly deposit reconciliation. This is the weekly version of the reconciliation report.
- Send daily discrepancy alerts when daily reconciliation finds a mismatch.
- Send weekly discrepancy alerts when weekly reconciliation finds a mismatch.
- Send the operator guide to Support before rollout. Support will receive the guide ahead of rollout.

## After launch

Review adoption after the first month.
