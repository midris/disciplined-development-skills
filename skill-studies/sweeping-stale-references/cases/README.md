# Case policy copies

`assessment-policy.txt` files are frozen policy inputs; retain their bytes and manifest identities.
The policy term “fixed-format score record” is defined in the [protocol glossary](../protocol.md#assessment-policy): one execution result, with repetition aggregation in the batch assessment.
That terminology pointer does not apply current rules retroactively to historical assessments.
Current collection uses the prospective [capture-2 evidence amendment](../protocol.md#session-evidence-amendment-capture-2); its authority is cited separately by each resumed attempt.
