# Count-free regression output reviews

The [approved design](../../../../../plans/specs/2026-10-31-ssr-count-free-regression.md) allocates four focused and six conditional remaining Opus-medium reviews.
The [packet plan](packet-plan.json) assigns every repair output exactly once, keeping the 18 reporting/non-use observations in active-session assessment.
The [evaluator ledger](evaluator-run-index.json) records actual calls; no replacement is allocated.

Each packet supplies complete original and final project mappings, all unique content objects, task, criteria, interpretation and neutral Git/runtime observations.
Unchanged qualified Click dependency files are identified by hashes; the original PNG is supplied in full, and the ZIP fixture is represented by a complete member/content manifest with its original archive hash.
The reviewer must read every required complete file before one independent first pass covering all run IDs and F1–F3 factors, then access the prior assessment separately.
Visible condition labels and same-family Opus subjects limit independence; these exposed cases do not establish reliability or a causal effect of the wording change.

Native Read/Glob/Grep are the only enabled review tools, under the qualified read-only boundary with skills disabled.
The controller retains the complete capture and verifies protected bytes, exact runtime and inventory.
The delivery audit checks complete reads and prior-access timing; active review then evaluates every functional factor and quality finding before marking the ledger audit complete.
The focused gate requires all four audited reviews and active reconciliation before any remaining-stage dispatch.

All ten reviews are complete. Independent first passes agree on all 144 functional factors across 48 unique repair outputs; no post-prior factor changed. Six reviewers read priors after their independent pass; four stopped beforehand and were compared by the active assessor without another call. See [final verification](../final-verification.json) for exact coverage and [assessment](../count-free-regression-01-assessment.md) for conclusions and limits.

The [retention incident](../retention-incident-01.json) records restoration of Git index stat caches changed during focused packet assembly; project/output/review input bytes were unaffected. The remaining packet builder disables index refresh and all 66 bundle inventories remained exact after packet construction. Codex nested tool outputs were inspected in full provider sessions where the stdout projection omitted them.
