# Shared scenario definitions and fixtures

These are controller criteria, subject inputs and preserved skill snapshots, not collected result reports.
The [protocol](../protocol.md) owns current scenario selection, collection status and interpretation.
Some preserved preparation records retain their original pre-dispatch status; use the protocol and [run collections](../runs/README.md) for observed outcomes.
A file named assessment.md here defines what to assess; batch assessments and execution results live under runs.
