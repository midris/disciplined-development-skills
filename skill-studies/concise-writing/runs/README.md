# Collected evidence and preparation

The [study protocol](../protocol.md) owns current decisions, coverage, interpretations and spending.
Each collection keeps its assessments, attempt indexes, result records and run-specific preparation together.
Historical identities retain their recorded Git paths and revisions; use those identities to retrieve the original bytes.
Current navigation links point to this layout. Current configs have rebased relative paths with identical supplied payloads; they do not replace the frozen configs recorded for completed calls.
Private raw evidence stays outside the repository at the paths in the indexes.
A completed record or an undispatched preparation directory supplies no authorization to rerun it.
