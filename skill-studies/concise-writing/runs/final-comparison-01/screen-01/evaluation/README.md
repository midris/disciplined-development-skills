# Final CW comment-screen output review

The [protocol](../../../../protocol.md) owns authority, progress and accounting.
Two approved Opus 5.5 medium sessions review all twelve completed comment artifacts, one six-output packet per subject provider.
Each packet compares three original-body and three revised-body repetitions with the same selected description.
These are explicit-load relative comparisons, with no no-CW control or native-selection measure.

[Inputs](inputs.json) freeze the packet, controller/support, subject indexes/reports and [prompt](prompt.md); the [ledger](evaluator-run-index.json) retains every attempted review and charge.
Use the pinned Claude 2.1.305 runtime with read-only native Read/Glob/Grep, no shell, skills or slash commands.
The reviewer is a fresh-context different-family evaluator relative to the active Codex assessor, with visible condition labels; it shares the Claude subjects' family.
The existing exact-binary runtime/boundary qualification is reused, with actual model/tool identity and protected bytes checked on both invocations.

Packets include every substantive non-skill task/source/notes/code input, setup wrapper, fixed criteria/policy/interpretation, complete saved outputs and descriptive comment counts/token checks.
Skill bodies, descriptions, raw traces and candidate hypotheses are excluded from output-quality review.
The controller inspects explicit body delivery separately.
Judge comments with the complete code against the complete factual inputs; equivalent wording, code-visible facts and useful reinforcement are allowed.
No literal duplicate keyword, shortest-output preference or fixed comment count substitutes for maintenance meaning and readability.
No subject-produced code is executed.

Every complete required file must be delivered before the emitted independent first pass; prior-assessment.md is read only afterwards.
Audit complete Read returns, any pre-prior search exposure, model/tool identity, protected bytes and inventories, then manually inspect every judgment and comparison before clearing the review.
The collector requires all twelve assessed subjects and blocks a second review until the first audit is cleared.
Unusable reviews stay charged; no automatic replacement, split, fallback or capacity transfer is authorized.
Stop after the two reviews and return the screen evidence to the owner before any top-up, candidate edit or adoption.
